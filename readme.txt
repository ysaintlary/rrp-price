Adds a « RRP » (Recommended Retail Price) field to WooCommerce products, with CSV import/export support.

== Description ==

SLS RRP Price adds a dedicated RRP (Recommended Retail Price) field to WooCommerce product pages.

= Features =

* Back-office field in the General/Pricing tab, right after the sale price
* Front-end display below the product price
* WooCommerce CSV import: auto-maps a "RRP" column to the custom field
* WooCommerce CSV export: includes the RRP column
* HPOS compatible
* Meta key: `_rrp_price`

== Installation ==

1. Upload the `sls-rrp-price` folder to `/wp-content/plugins/`
2. Activate the plugin through the "Plugins" menu in WordPress
3. Edit any product — the RRP field appears in the General tab under Pricing
